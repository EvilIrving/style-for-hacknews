# Store listing

## Short description

Improve Hacker News readability with local typography, spacing and metadata controls.

## Long description

Style for Hacker News makes Hacker News easier to read with refined typography, calmer spacing, readable comment-depth indicators and a compact local control panel. Choose a font and hide story metadata when you want less visual noise. Preferences remain in browser storage and the extension does not collect or transmit user data.

## Submission facts

Category: Functionality & UI. Single purpose: locally change the presentation of `news.ycombinator.com` for readability. Permission: `storage` saves font and metadata preferences; the Hacker News host permission applies local styles and controls. Data collection: none. Privacy policy: `https://evilirving.github.io/style-for-hacknews/privacy.html`. Support: `https://github.com/EvilIrving/style-for-hacknews/issues`.
