Install

Install the release package in a desktop browser.

Download the matching package from GitHub Releases and unzip it to a folder you will keep.
Open chrome://extensions or edge://extensions, enable Developer mode, choose Load unpacked, then select the unzipped folder.
For Firefox, open about:debugging#/runtime/this-firefox, choose Load Temporary Add-on, then select the package manifest from the unzipped folder.
