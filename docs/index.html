Style for Hacker News

A quieter reading layer for Hacker News, with refined typography, spacing and local preferences.

View releasesPrivacy

What it changes

Choose a reading font, reduce visual noise by hiding metadata, and make nested comment threads easier to scan. Preferences stay in your browser.

Install

Download a package from GitHub Releases, unzip it, then load the directory from your browser’s extension management page. See the complete installation guide.

Boundaries

This is an independent extension for news.ycombinator.com. It changes presentation only; it does not collect, transmit or sell user data.
